How it works, in one screen

  1. Paste or upload evidence about your agent: a persona file, memory or notes, skill files, a goals list, a delivery log, or a generic JSON profile. Any agent platform works: Muse, ChatGPT, Claude, Gemini, or other.
  2. Press Run audit. The server screens the text for personal data and injected instructions, then Clocked Extract pulls evidence with source quotes, Fill builds your profile, Decide grades autonomy and honesty, and Verify checks each claim against your source text.
  3. Get your level chart. Six dimensions - Identity, Knowledge, Skill, Span, Reliability, Integrity - averaged into one composite score and level. Only source-matched submitted fields count in full; estimated fields count at half weight; missing fields are shown as missing. Source matching does not independently verify private agent files. Download the 9:16 card (1080 x 1920) and share it.

Statistics only, please: counts and grades, never passwords, API keys, or full conversation text. Personal data is redacted before scoring.
